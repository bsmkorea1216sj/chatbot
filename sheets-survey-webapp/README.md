# AI 사용 설문 웹앱 (Google Sheets + Apps Script)

응답이 Google 스프레드시트의 `Responses` 시트에 자동으로 쌓이는 2문항 설문 웹앱입니다.

- 문항 1: 내가 사용하는 AI는 무엇인가? (제미니 / 챗지피티 / 클로드 / 기타 - 직접입력)
- 문항 2: 무료인가 유료인가? (무료 / 유료)

## 구성 파일

- `Code.gs` — 서버 스크립트 (`doGet`으로 폼 렌더링, `submitSurvey`로 응답 저장)
- `Index.html` — 설문 폼 UI
- `appsscript.json` — Apps Script 매니페스트 (웹앱 배포 설정)

## 배포 방법

1. 응답을 저장할 Google 스프레드시트를 새로 만듭니다.
2. 스프레드시트 메뉴에서 **확장 프로그램 > Apps Script**를 엽니다.
3. 기본 생성된 `Code.gs` 내용을 이 저장소의 `Code.gs` 내용으로 교체합니다.
4. Apps Script 편집기에서 **파일 > 새로 만들기 > HTML 파일**로 `Index`라는 이름의 파일을 만들고, 이 저장소의 `Index.html` 내용을 붙여넣습니다. (파일명이 반드시 `Index`여야 `doGet()`에서 정상 참조됩니다.)
5. (선택) 프로젝트 설정에서 `appsscript.json` 표시를 켜고 내용을 이 저장소의 `appsscript.json`으로 맞춰줍니다.
6. 우측 상단 **배포 > 새 배포**를 클릭합니다.
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (설문 응답자가 로그인 없이 제출 가능)
7. **배포**를 누르고 생성된 웹 앱 URL을 응답자에게 공유합니다.
8. 처음 제출 시 시트에 `Responses` 탭이 자동 생성되고, 타임스탬프/응답 내용이 한 행씩 쌓입니다.

## 참고

- 코드를 수정한 뒤에는 **배포 > 배포 관리 > 수정(연필 아이콘) > 새 버전**으로 다시 배포해야 웹 앱에 반영됩니다.
- `appsscript.json`의 `access`를 `ANYONE_ANONYMOUS`로 설정해 두었으므로, 실제 배포 시 Apps Script 배포 대화상자에서도 동일하게 "모든 사용자"로 맞춰야 링크만으로 접근 가능합니다. 조직 내부에만 공유하려면 `ANYONE`(Google 로그인 필요) 등으로 바꾸세요.
