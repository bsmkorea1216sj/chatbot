## 과제 ③ · 여성 액세서리몰 웹앱 만들기 (교안 57쪽)

**목표:** 7번 셀에서 물리 설계를 적용한 `shop`을 사용해, 상품과 주문 내역을 조회하는 웹앱을 완성하세요. 화면 틀은 제공하며, 아래 두 조회 함수의 SQL은 직접 작성합니다. 수업용 데이터로 Colab 미리보기에서 확인하세요.

1. **상품 조회 (25점)** — `product_query`에서 ‘전체’는 전체 상품을, ‘귀걸이’처럼 특정 카테고리를 입력하면 해당 상품만 표시합니다. 상품명 검색과 카테고리를 함께 적용해 상품명·카테고리·현재가·재고를 보여 주세요. 입력은 SQL에 직접 붙이지 않고 `%s`와 파라미터 튜플을 사용합니다.
2. **주문 내역 (35점)** — `order_query`에서 `orders → order_details → products`를 키로 연결합니다. 고객 번호로 필터링하고 최신 주문부터 표시합니다. 주문 당시 단가는 현재 판매가인 `products.price` 대신 `order_details.unit_price`를 사용합니다. 주문 이력이 없으면 ‘조회 결과가 없습니다’가 표시되는지 확인하세요. 주문이 있는 화면이 필요하면 12-3으로 넘어오기 전에 남겨 둔 실습 주문을 사용하세요.
3. **오늘 배운 설계 검증 (30점)** — 상품 재고 `CHECK` 또는 주문상세 외래키가 막는 오류 한 가지를 과제 ① 결과로 설명하세요. 아래 셀에서 조회 실행 계획을 확인하고 인덱스가 지원할 수 있는 조건을 적으세요. 소량 데이터에서는 순차 스캔도 정상입니다. 출력에 나타난 계획을 근거로 설명하세요.
4. **제출 (10점)** — 상품 필터와 주문 조회 화면, 실행 계획, 제약 조건 설명을 제출합니다. 조회 결과 화면에는 이메일·주소·비밀번호를 넣지 마세요. 결과를 확보한 뒤 **8번 셀에서 최종 삭제**를 진행합니다.

두 조회 함수를 수정한 뒤 웹앱 셀을 다시 실행하세요.
