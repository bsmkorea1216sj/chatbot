# AI Education — AI 교육 통합 인덱스

AI 교육 프로그램을 과정별로 분리해서 운영합니다. **강의용 교안**은 교육 흐름과 개념을 설명하고, **실습 가이드북**은 수강생이 화면·명령어·검증 결과를 따라갈 수 있도록 구성합니다.

## 교육과정

| 교육과정 | 상태 | 바로가기 |
| --- | --- | --- |
| 에이전틱 AI 풀 웹앱 만들기 | 1~3일차 가이드북 초안 | [과정 목차](./agentic-ai-full-webapp/README.md) |

향후 새로운 교육과정이 생기면 `ai-education/<course-slug>/` 폴더를 따로 추가하고, 이 목록에 연결합니다. 아직 기획 중인 과정의 빈 폴더는 만들지 않습니다.

## 혼선 방지 규칙

- 이 교육의 기준 경로: `chatbot/ai-education/agentic-ai-full-webapp/`
- `chatbot/db-course/`는 기존 DB 수업 공동작업 폴더입니다. 이번 교육과 분리합니다.
- [클라우드 아키텍처 가이드북](https://github.com/bsmkorea1216sj/cloud_architecture)은 **별도 저장소**로, 이번 작업에서 수정하지 않습니다.
- 다른 GitHub 저장소와 `chatbot` 루트의 앱, 워크플로, 환경설정도 수정하지 않습니다.
- 코스마 홈페이지 개발 경험은 교육용 사례로 재구성하되, 운영 소스·내부 자료·개인정보·인증 키를 공개 저장소로 복사하지 않습니다.
- 현재 Markdown 목차는 클릭형 링크입니다. AWS 가이드북과 같은 **왼쪽 고정 메뉴 웹 UI**는 별도 구현·배포 단계에서 구축합니다.
