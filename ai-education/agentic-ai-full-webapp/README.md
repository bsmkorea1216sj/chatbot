# 에이전틱 AI 풀 웹앱 만들기

**현장 프로젝트 개발 경험을 따라하며 배우는 AI 웹앱 설계·개발·배포 과정**

## 교육 설계 원칙

- **교안(PPT):** 기존 자료의 DB·API·AI·클라우드 아키텍처 개념을 활용하여 '왜, 어떤 순서로 개발하는가'를 설명합니다.
- **가이드북(Markdown):** '무엇을 클릭하고 입력할지 → 결과를 어떻게 확인할지 → 오류가 나면 어떻게 복구할지'를 단계적으로 안내합니다.
- **사례(KOSMA):** 코스마 홈페이지 개발 당시의 요구사항 정리, Claude Code 협업, 기능 수정, 배포·운영 과정에서 배울 점을 교육용으로 재구성합니다. 구체적 작업 로그는 추가 검증 후 보강합니다.
- **확장(Oracle):** 코스마 실제 백엔드에 사용하지 않았던 **Oracle Database 연동**은 신규 교육용 실습 트랙으로 구분합니다.

## 제작할 결과물

1. 요구사항·아키텍처 요약서
2. 실행 가능한 교육용 웹앱(화면 + API + 데이터 저장)
3. 클라우드 배포와 오류 해결 기록
4. GitHub에 버전 관리된 실습 소스와 검증 체크리스트

## 강의 자료 상태

이 폴더에는 **과정 구성 및 실습 가이드 초안**만 등록되어 있습니다. 명령의 환경별 검증, 실제 화면 캡처, 기존 PPT 내용과 Claude Code 작업 로그 대조, 왼쪽 고정 목차 웹 UI는 아직 완료된 것으로 표시하지 않습니다.
