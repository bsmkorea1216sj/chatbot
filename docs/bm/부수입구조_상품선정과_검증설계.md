# 월 100만 원 부수입 구조 — 상품 선정과 검증 설계

> 작성일: 2026-11-02
> 입력: "프로젝트: 월 100만 원 부수입 구조 (빅데이터 김교수)" 기획 블록
> 산출물: ① 후보 A·B 비교표 ② 설문 문항 ③ 시연 랜딩페이지·신청 폼

---

## 1. 후보 A·B 비교표

**A.** 강사용 AI 수업 준비 자동화 (강의안·슬라이드·퀴즈를 한 차시 단위로)
**B.** 실제로 작동하는 AI 자동화 도구 만들기 (예: 주식 블로그 자동화)

| 기준 | A. 강사용 수업 준비 | B. 주식 블로그 자동화 |
|---|---|---|
| **구매자** | 가르치는 사람 (대학·사내강사·학원·공공 교육담당) | 부수입을 원하는 일반인 |
| **예산 출처** | 강의료 또는 기관 교육예산. **시간을 사는 구조** → 저항 낮음 | 여윳돈. **기대 수익으로 사므로** 기대치가 비현실적 |
| **통증의 크기** | 한 차시 3~8시간 × 15차시 = 45~120시간/학기. 시간당 10만원 환산 시 수백만원 | "더 벌고 싶다"는 **욕구**. 구체적 시간 손실이 아니라 ROI 계산 불가 |
| **지금 가진 증거** | **이미 있음** — 대학·AICA·K-MOOC 자료를 Claude로 제작 중. 즉시 시연 가능 | **없음.** 새로 만들어야 하고, 증거가 "블로그 수익"이면 몇 달 소요 |
| **재구매** | 학기마다, 과목 추가마다 반복 | 일회성. 도구 받으면 끝 |
| **경쟁 밀도** | "AI 업무 자동화" 일반은 레드오션이나 **"수업 준비"는 좁아서 비어 있음** | **레드오션.** 유튜브에 무료로 넘침 → 가격 경쟁 |
| **성과 책임 범위** | 성과 = "강의안이 나왔는가" → **100% 통제 가능** | 성과 = "돈을 벌었는가" → **통제 불가.** 알고리즘·검색 노출·주제에 달림 |
| **규제·분쟁 리스크** | 낮음. 단 학교 저작권·시험문제 보안 주의 | **종목·투자 판단이 들어가면 유사투자자문(자본시장법) 접점.** 대량 자동생성 글은 검색 노출 제한 위험 |
| **유튜브 조회수** | 낮음 (청중이 좁다) | 높음 (돈·주식) |
| **검증 소요** | **1~2주** — 이미 강사 네트워크(AICA·K-MOOC) 안에 있음 | 수개월 — 수익 증거가 나와야 팔림 |
| **실패 시 손실** | 본인 업무 자동화는 남음 | **"돈 번다더니" 평판 리스크** |

### 결론: A 단일 집중. B는 폐기.

세 가지가 결정적입니다.

1. **증거를 이미 갖고 있습니다.** A는 오늘 시연할 수 있고 B는 몇 달 뒤에야 가능합니다.
   자산 목록의 "실제 대학·AICA·K-MOOC 강의 자료를 Claude로 제작 중"이 이 프로젝트의
   유일한 비대칭 자산입니다. 그 자산을 그대로 쓰는 쪽이 A입니다.
2. **A만 약속을 지킬 수 있습니다.** B의 약속("수익")은 내가 통제하지 못하는 변수에
   달려 있어, 상품이 구조적으로 약속을 못 지킵니다. 환불과 불만이 기본값이 됩니다.
3. **B를 유입용으로 쓰는 안도 권하지 않습니다.** 조회수는 나오지만 **주식으로 온
   사람은 강사가 아닙니다.** 깔때기 입구와 출구의 청중이 어긋나 전환이 안 됩니다.

### 유입은 B가 아니라 이 축으로

현재 채널 주제(빅데이터 분석·AI 업무자동화·파이썬)에서 **"가르치는 사람"** 세그먼트로
좁히는 영상. 조회수는 B보다 낮지만 **깔때기가 일직선**입니다.

- "교수가 Claude로 15주 강의 자료 만드는 과정" (전 과정 공개)
- "AI가 만든 퀴즈가 틀렸을 때 어디를 어떻게 고치는가" ← 블록 검증계획 4번
- "실습 예제 코드만 자동으로 만드는 법"

### 세그먼트 확장 한 칸 — 사내강사·교육담당자

A의 1차 타겟은 접근 가능한 대학·AICA 강사입니다. 다만 **기업 사내강사와 교육담당자**는
예산이 회사 돈이고 결제 권한이 있어 단가를 훨씬 높게 받을 수 있습니다.
게이트 1을 통과하면 2차 타겟으로 넣으십시오.

## 2. 설문 문항

### 설계 원칙

- **"사시겠습니까?"를 묻지 않습니다.** 가정형 질문의 긍정 응답은 신호가 아닙니다.
- 측정하는 것: 세그먼트 / **실제 시간** / 빈도 / 현재 해결법 / **과거 지출** / 구체 사례
- **과거에 돈을 써 본 경험이 가장 강한 예측 변수**입니다 (7번).
- 마지막 문항은 의향이 아니라 **실제 행동 요청**입니다. 그게 진짜 시험입니다.
- 2분 안에 끝납니다.

### 긴 버전 (지인 강사 + 커뮤니티, 9문항)

1. 어디에서 가르치십니까? *(대학 / 기업 사내 / 학원·사설 / 공공기관 / 기타)*
2. 한 학기(또는 한 과정)에 담당하시는 차시는 몇 개입니까?
3. **한 차시 자료를 처음부터 만들 때 실제로 몇 시간 걸립니까?**
   *(1시간 이하 / 1~3시간 / 3~6시간 / 6시간 이상)*
4. 그 시간 중 **가장 오래 걸리는 단계 하나**는 무엇입니까?
   *(슬라이드 구성 / 실습 예제·코드 / 퀴즈·과제 / 강의 대본 / 자료 조사)*
5. **최근 한 달 안에 그 작업 때문에 밤을 새우거나 주말을 쓴 적이 있습니까?** *(예 / 아니오)*
6. 지금은 어떻게 해결하십니까?
   *(직접 다 만듦 / 기존 자료 재사용 / 조교·외주 / AI 도구 사용 중 / 기타)*
7. **지난 1년간 수업 자료 제작에 돈을 써 보신 적이 있습니까? 있다면 무엇에 얼마입니까?**
   *(자유 응답)*
8. AI 도구를 써 보셨다면, 왜 끝까지 쓰지 못하게 되었습니까?
   *(결과물 품질 / 내 과목에 안 맞음 / 수정이 더 오래 걸림 / 사용법을 모름 / 잘 쓰고 있음)*
9. **[행동]** 한 차시 자료를 1시간 안에 함께 만드는 시연을 **29,000원**에 엽니다.
   참여하실 의향이 있으면 연락처를 남겨 주세요. *(신청 링크)*

### 짧은 버전 (오픈채팅·커뮤니티, 3문항)

낯선 사람은 9문항을 채우지 않습니다. 이것만 던지십시오.

1. 한 차시 수업 자료 만드는 데 몇 시간 쓰십니까?
2. 그중 가장 오래 걸리는 단계는 어디입니까?
3. 한 차시를 1시간에 같이 만드는 시연, 29,000원. 신청하시겠습니까? *(링크)*

### 가격을 1~2만원에서 29,000원으로 올린 이유

블록에는 "1~2만 원짜리 1시간"으로 적혀 있지만 두 가지 때문에 올렸습니다.

- **노쇼**: 가격이 낮으면 결제 후 안 옵니다. 검증 데이터가 오염됩니다.
- **신호 품질**: 시간당 강의료 5~15만원인 사람에게 1만원은 오히려 무성의하게 읽힙니다.

29,000원 + **"결과물이 안 나오면 전액 환불"**이 조합입니다. 환불 보장이 가격 저항을
없애면서 결제 행위의 신호는 유지합니다.

## 3. 사전 판정 기준 (블록 검증계획 5번의 N 채우기)

**측정 전에 기준을 고정합니다. 나중에 결과를 보고 기준을 바꾸면 검증이 아닙니다.**

| 지표 | 통과 기준 | 미달 시 |
|---|---|---|
| 응답 20명 중 3번 "3시간 이상" | **10명 이상** | 통증이 약함 → 상품 폐기 |
| 7번 과거 지출 경험 | **5명 이상** | 지불 의사 없음 → 세그먼트 교체(대학→사내강사) |
| **모르는 사람 실제 결제** | **3명 이상** | 지인 외 수요 없음 → 유입 축부터 재설계 |
| 시연 3회 후 결과물 완성률 | **3/3** | 상품이 아직 안 됨 → 범위 축소 |

**N = 3명**으로 잡은 이유: 1명은 우연, 2명은 인맥 가능성, 3명이면 패턴입니다.
그리고 시연을 3회 돌리면 상품 자체의 완성도도 같이 검증됩니다.

### 지인 결제를 따로 집계하십시오

블록 리스크에 "지인 결제는 인맥 영향 큼"이라고 적어 두셨습니다. 맞습니다.
**지인 결제는 숫자에 넣지 말고 별도 칸에 기록**하십시오. 판정은 모르는 사람 3명으로만
합니다. 지인 결제는 시연 리허설 용도입니다.

## 4. 다음 단계 순서

```
게이트 0  설문 20명 (3일)              → 통증·지불 의사 확인
게이트 1  모르는 사람 3명 유료 시연      → 수요 확인. 미달 시 폐기
게이트 2  소요 시간 실측 + 전후 비교     → 여기서부터 제목에 수치 사용 가능
게이트 3  전자책 (절차 템플릿)           → 전환율 1~3% 전제로 모수 계산
게이트 4  녹화·유료 강의 (전체 실습·오류 해결)
```

**게이트 2를 통과하기 전에는 "N시간 → M시간" 을 어떤 홍보물에도 쓰지 않습니다.**
측정하지 않은 수치는 과장이고, 한 번 쓰면 되돌릴 수 없습니다.

## 5. 아직 모르는 것 (측정 필요)

자산 목록의 "미확인" 항목이 상품 선정에는 영향이 없었지만, **게이트 3의 모수 계산에는
반드시 필요**합니다.

- [ ] 유튜브 구독자 수, 최근 10개 영상 평균 조회수
- [ ] 시청자 구성 (연령·성별·유입 키워드) — **"가르치는 사람" 비중이 핵심**
- [ ] 블로그 월 방문자, 자료 다운로드 신청 건수
- [ ] 기존 유료 신청자 명단 규모 ← **게이트 1의 가장 빠른 모집 경로**

전자책 전환율 1~3%가 맞다면, 100권을 팔려면 **도달 3,300~10,000명**이 필요합니다.
현재 채널이 그 모수를 만들 수 있는지는 위 숫자를 봐야 알 수 있습니다.
