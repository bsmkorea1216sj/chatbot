## 3. 네 번 반복된 패턴 ★ 스터디의 핵심

네 아이템을 각각 분석했더니 **같은 실수가 다섯 가지 반복**됩니다.

### (1) 검증보다 개발이 먼저였다
아이템 1·2는 **코드가 완성됐는데 고객이 0명**입니다. 가장 비싼 순서로 일했습니다.

### (2) 무료·저가 대체재를 뒤늦게 발견했다
- 예약 SaaS → **카카오톡 예약하기가 무료**
- AI 챗봇 월 99,000원 → **사이드톡 그로스가 정확히 99,000원**
- 고객관리 → 원장님 **개인 카톡** (공짜·이미 익숙)

### (3) 가격이 전달 방식과 맞지 않았다
- 월 20,000원인데 **사람이 직접 세팅** → LTV/CAC 0.6~1.1
- 월 22,000원인데 **AI 모델 원가**가 변동비 → 50% 예산 규칙으로 방어해야 했음

### (4) 가진 자산을 매번 3순위로 밀었다
유튜브 청중이 유일한 비대칭 자산인데, 기획서마다 방문 영업·협회가 1순위였습니다.
심지어 "청중 보유 창업자 20배" 데이터를 **본인이 인용해 놓고** 그렇게 했습니다.

### (5) 전부 플랫폼 위에 지었다
카카오 · 네이버 · 카페24 · GCP. 플랫폼이 기능을 내리면 끝납니다.
→ **12개월 내 회수되는 규모로만** 설계해야 합니다.

### 교훈 한 문장

> **만들기 전에 모르는 사람 3명에게 돈을 받는다.**

## 4. 아이템은 4개지만 자산은 2개다

### (1) 코드 기반 — 어떤 아이템에도 그대로 쓴다
`services/research-api/` 의 **Firebase 인증 / 예약·정산 원장(reserve·settle) / Cloud
Tasks 워커 / 중복요청 방지**, 그리고 `scripts/gcp_deploy/` 의 **15단계 배포 실행기**.
새 아이템을 시작해도 **인증·과금·배포를 다시 만들 필요가 없습니다.**

### (2) 유튜브 청중 (AI노마드)
유일하게 복제 불가능한 자산입니다. 그런데 **구독자 수·조회수·시청자 구성이 미확인**이라
아직 계산에 넣지 못하고 있습니다. 이 숫자가 없으면 전자책 모수도, 전환율도 못 셉니다.

### 브랜드가 4개로 흩어져 있다
`BSM` / `BSN Korea` / `AI노마드챗봇` / `AI노마드연구소` / `빅데이터김교수`
→ **`AI노마드` 하나로 통일**해야 청중이라는 자산이 한 곳에 모입니다.
