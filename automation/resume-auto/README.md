# 평택대 이력서 자동 입력 셋팅

제미니(Gemini CLI)가 브라우저를 열어 이력서 폼을 **채워주는 것까지** 합니다.
**제출은 본인이 직접** 누릅니다.

대상: https://login.ptu.ac.kr/nx/index.html?loginGbn=pfic

## 설치

```powershell
# 윈도우
.\setup.ps1
```

```bash
# 맥 / 리눅스
./setup.sh
```

하는 일: Gemini CLI 설치 → Playwright 크로미움 내려받기 → `resume.yaml` 생성.

## 쓰는 법

1. 첨부할 파일(이력서 PDF, 증빙)을 `files/` 에 넣습니다
2. **이 폴더에서** `gemini` 실행
3. `/mcp` 로 `playwright`, `filesystem` 연결 확인
4. 아래 문장들로 대화하면서 진행합니다

`resume.yaml` 을 손으로 채워도 되고, **말로 불러줘도 됩니다.**

## 대화 치트시트 — 이대로 말하면 됩니다

**내용 채워 넣기 (손으로 안 치셔도 됩니다)**

```
받아쓰기 시작할게
경력 추가. 2020년 3월부터 평택대 겸임교수, 데이터분석 담당
논문 추가. 2024년 한국데이터정보과학회지, 단독저자
```
→ 한 항목씩 되읽어 확인받고 `resume.yaml` 에 저장합니다.

**사이트에 입력**

```
사이트 열어줘
이 페이지 구조 알려줘          ← 처음에 꼭 한 번
다 채워줘
```

**확인과 수정**

```
지금 화면 뭐가 들어갔어?
yaml 이랑 화면이 같은지 봐줘    ← 다른 칸만 표로 보여줍니다
박사 졸업을 2019년 2월로 고쳐
3번 항목 다시 채워줘
그거 빼줘
```

**하면 안 되는 말**

```
제출해줘     → 거절합니다. 직접 누르셔야 합니다
저장해줘     → "파일 저장인가요, 사이트 저장인가요?" 되묻습니다
```

5. **제출 버튼은 본인이 확인하고 누릅니다**

로그인 세션은 `.browser-profile/` 에 남아 다음부터는 보통 로그인을 다시 하지 않습니다.

## 설계상 지킨 것

| | |
|---|---|
| **비밀번호** | 제미니에게 주지 않습니다. 로그인 화면이 나오면 멈추고 사람에게 넘깁니다 |
| **제출** | 자동으로 누르지 않습니다. `GEMINI.md` 의 1번 제약 |
| **확인 절차** | `trust` 를 켜지 않아 도구 호출마다 확인을 받습니다 |
| **개인정보** | `resume.yaml`, `files/`, `.browser-profile/` 은 `.gitignore` 로 제외됩니다 |
| **지어내기 방지** | `resume.yaml` 에 없는 값은 비워 두고 보고합니다 |
| **수정 전 확인** | 파일을 고치기 전에 전/후를 보여주고 확인받습니다 |
| **되돌리기** | 고치기 직전 상태가 `resume.backup.yaml` 로 남습니다 |
| **"저장" 모호성** | 파일 저장인지 사이트 저장인지 반드시 되묻습니다 |

## ⚠️ 먼저 확인해야 할 것 — 되는지 안 되는지가 여기서 갈립니다

주소의 `/nx/` 가 **Nexacro 계열 런타임**을 가리킬 가능성이 있습니다.
한국 대학·공공 포털에 흔한 방식인데, 화면이 일반 HTML 이 아니라 런타임이 그리는
구조라 **DOM 선택자로 자동화가 되지 않습니다.**

`gemini` 를 띄우고 첫 지시를 이렇게 주십시오.

> 사이트를 열고, 이 페이지가 일반 HTML 폼인지 Nexacro 같은 런타임인지 먼저 알려줘. 아무것도 입력하지 마.

- **일반 HTML 이면** → 그대로 진행하시면 됩니다
- **Nexacro 계열이면** → 자동화를 권하지 않습니다. 좌표를 찍어 누르는 방식은
  화면이 조금만 바뀌어도 엉뚱한 칸에 입력되므로 `GEMINI.md` 에서 금지해 두었습니다.
  이 경우 자동화 대상을 **이력서 문서 생성**(제출용 PDF/한글 양식 작성)으로
  바꾸는 편이 실익이 큽니다.

- 지원 마감 직전에 처음 돌리지 마십시오. 여유 있을 때 한 번 끝까지 돌려보십시오
