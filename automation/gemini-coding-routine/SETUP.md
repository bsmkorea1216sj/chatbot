# 앱 자동코딩 MCP 루틴 설치 (제미나이 실행용)

이 문서는 **제미나이에게 그대로 주는 지시서**다.
프로젝트 폴더에서 `gemini` 를 띄우고 아래 블록을 붙여넣으면 제미나이가 직접 설치한다.

패키지 이름과 버전은 npm 레지스트리에서 확인한 값이다 (확인일 2026-11-22).

---

## 붙여넣을 내용

```text
이 프로젝트에 앱 코딩용 MCP 루틴을 설치해라. 아래를 순서대로 하고, 각 단계가 끝나면 멈추고 결과를 보고해라.

[지켜야 할 규칙]
- 이미 있는 파일을 덮어쓰기 전에 전/후 차이를 보여주고 내 확인을 받아라.
- 어떤 파일에도 토큰·API 키·비밀번호를 쓰지 마라. 필요하면 환경변수 참조로 두고 나에게 알려라.
- MCP 설정에 trust 옵션을 켜지 마라.
- 설치만 해라. 이 작업 중에 프로젝트 코드를 고치지 마라.

[1단계] 현재 상태 확인
.gemini/settings.json 과 GEMINI.md 가 이미 있는지 확인해서 알려줘라. 있으면 내용을 보여줘라.

[2단계] .gemini/settings.json 작성
아래 내용으로 만들어라. 이미 있으면 mcpServers 항목만 병합하고 기존 설정은 지우지 마라.

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem@2.4.0", "."]
    },
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp@4.7.3"]
    },
    "sequential-thinking": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sequential-thinking@2.2.0"]
    },
    "memory": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-memory@2.2.1"]
    }
  }
}

버전은 고정값이다. @latest 로 바꾸지 마라. npx 가 매번 다른 버전을 받아 어제 되던 것이 오늘 깨진다.
이 프로젝트가 웹앱이면 playwright 서버도 넣을지 나에게 물어라.

[3단계] GEMINI.md 작성
아래 내용으로 만들어라. 이미 있으면 내용을 보여주고 어떻게 합칠지 물어라.

# 역할
이 저장소의 코드를 고치고 늘린다. 한국어로 보고한다.

# 제약
1. 라이브러리 API 는 기억에 의존하지 말고 context7 로 먼저 확인한다.
   확인이 안 되면 추측하지 말고 묻는다.
2. 한 번에 하나만 바꾼다. 여러 파일을 동시에 고치지 않는다.
3. 코드를 바꾸면 반드시 테스트를 실행한다. 실행 결과를 그대로 보여준다.
   테스트가 없으면 먼저 만든다.
4. 테스트를 건너뛰거나 비활성화해서 통과시키지 않는다.
5. 바꾸기 전에 바뀌는 부분만 전/후로 보여주고 확인을 받는다.
6. 커밋 메시지는 무엇을 왜 바꿨는지 쓴다. 파일 목록 나열이 아니다.
7. 비밀값(토큰·키)을 코드나 설정 파일에 쓰지 않는다. 환경변수로 받는다.
8. 사람이 확인해야 하는 것(배포, 삭제, 외부 전송)은 하지 않고 보고한다.

# 작업 루프
계획 제시 -> 확인 받기 -> 구현 -> 테스트 실행 -> 실패하면 수정 -> 결과 보고 -> 커밋

# 완료 조건
- 테스트가 통과했고 그 출력을 보여줬다
- 바뀐 동작을 한 문장으로 설명했다
- 확인하지 못한 것과 추측한 것을 따로 적었다

[4단계] 이 프로젝트에 맞게 다듬기
이 저장소의 언어, 테스트 명령, 빌드 명령을 찾아서 GEMINI.md 의 "작업 루프"에
실제 명령을 적어 넣어라. 찾지 못하면 추측하지 말고 나에게 물어라.

[5단계] 마무리 보고
다음을 보고해라.
- 만든 파일과 경로
- 설정한 MCP 서버 목록
- 내가 지금 해야 할 일 (gemini 재시작 필요 여부 포함)
```

## 붙여넣은 뒤에 할 일

1. 제미나이가 설치를 마치면 **`gemini` 를 종료하고 다시 실행한다.**
   MCP 서버는 시작할 때 읽히므로 재시작 전에는 붙지 않는다.
2. `/mcp` 를 쳐서 서버 네 개가 연결됐는지 확인한다.
3. 첫 작업을 지시한다. 예: `이 프로젝트 구조를 파악하고 테스트를 한 번 돌려봐.`

---

## 서버가 하는 일

| 서버 | 쓰임 |
|---|---|
| **filesystem** | 코드 읽기·쓰기 |
| **context7** | 최신 라이브러리 문서 조회. **API 환각을 막는다** |
| **sequential-thinking** | 복잡한 설계를 단계로 쪼갠다 |
| **memory** | 프로젝트 결정사항을 기억한다 |
| playwright (선택) | 웹앱이면 브라우저로 동작 확인 |

앱 코딩에서 가장 값을 하는 것은 **context7** 이다.
모델이 옛 API 를 기억해서 쓰는 일을 줄여 준다.

## 주의

**`@modelcontextprotocol/server-github` 는 쓰지 않는다.**
npm 에서 `Archived and unmaintained; no security guarantees` 로 폐기 표시되어 있다.
GitHub 작업은 공식 `github/github-mcp-server` 를 쓰거나, 셸에서 `git` 과 `gh` 를 쓴다.
폐기된 패키지에 개인 액세스 토큰을 넘기지 않는다.

**`trust: true` 를 켜지 않는다.**
확인 절차를 건너뛰는 옵션이다. 파일을 쓰고 셸을 실행하는 구성에서는 위험하다.
